# Support

Epyatis MCP Central is an early-stage open-source project without a commercial support commitment or response-time SLA.

## Where to ask

- **Reproducible bug:** use the bug report form.
- **Feature or architecture proposal:** use the feature request form.
- **Documentation problem:** use the documentation issue form.
- **Implementation discussion:** comment on the relevant issue or pull request so the decision remains public and searchable.

Before opening an issue, search existing issues and read [Known limitations](docs/KNOWN_LIMITATIONS.md). Include the commit/version, operating system, Python version, isolated reproduction steps and sanitized logs.

## What not to post publicly

Do not include bearer tokens, API keys, OAuth files, `.env` contents, customer data, private URLs or exploit details. Report suspected vulnerabilities through [SECURITY.md](SECURITY.md). Report sensitive community-conduct incidents through the private channel described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Current support boundary

Support is limited to local development and isolated evaluation. Public-internet, production, highly available and multi-replica deployments are outside the supported boundary while the blockers in the [Roadmap](ROADMAP.md) remain open.
